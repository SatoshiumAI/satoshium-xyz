# 🎨 Experimental Interface Style Guide

This document defines visual and structural style expectations for modules
within the **satoshium-xyz** repository.

Satoshium Labs interfaces should remain consistent with the broader platform
while allowing controlled experimentation with new layouts and interaction
models.

---

# 🧭 Purpose

The Labs layer supports interface exploration without fragmenting the visual
identity of the Satoshium platform.

This guide ensures:

- visual consistency across experiments
- readability of prototype systems
- compatibility with platform navigation
- smooth migration into infrastructure layers

---

# 🎨 Visual Theme

Experimental modules should follow the core Satoshium visual palette:

background: #07090d
panel: #0c1018
text: #e8edf7
muted: #9aa7bd
accent gold: #d6a34a
accent gold2: #f4c36a
border line: rgba(214,163,74,.18)

This preserves continuity across the ecosystem.

---

# 🪪 Card-Based Layout System

Labs modules should prefer structured card layouts using:

- rounded panels
- subtle gradients
- watermark seal backgrounds
- soft shadows
- restrained hover effects

Example usage:

.card
.module
.section-card

Card-based systems improve clarity across simulations and dashboards.

---

# 🧱 Layout Expectations

Interfaces should prioritize:

- clear section hierarchy
- readable spacing
- modular component structure
- responsive layout behavior
- consistent navigation placement

Avoid dense single-column text blocks when interactive structures are possible.

---

# 🧪 Experimental Flexibility

Labs modules may introduce:

- alternate interaction models
- simulation dashboards
- timeline interfaces
- signal consoles
- decision environments
- prototype reasoning tools

Visual experimentation is encouraged when it improves system understanding.

---

# 📡 Navigation Integration

Experimental pages should include:

topbar-loader.js
footer.html
sayings.js

to maintain continuity with the Satoshium platform environment.

---

# 🧠 Typography

Preferred typography:

system-ui
Segoe UI
Roboto
Arial
sans-serif

Interfaces should emphasize:

- clarity over decoration
- spacing over density
- structure over ornamentation

---

# 🪶 Motion Guidelines

Animation should remain subtle and purposeful.

Recommended:

- short fade-in transitions
- small elevation hover effects
- minimal transform motion

Avoid:

- large motion shifts
- distracting transitions
- decorative animation without function

---

# 🔬 Simulation Interface Extensions

Simulation environments may include:

- status indicators
- scenario controls
- decision pathways
- system feedback panels
- signal dashboards

These elements should remain visually aligned with the platform theme.

---

# 📘 Migration Compatibility

Interfaces designed within Labs should remain compatible with later promotion
into:

satoshium.ai
satoshium.net
satoshium.info

Maintaining style alignment reduces integration friction.
