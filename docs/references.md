# 🔗 References & Platform Context

This document provides contextual references supporting the experimental
systems contained within the **satoshium-xyz** repository.

Satoshium Labs operates as the experimental interface layer of the Satoshium
platform, where coordination models, simulations, and intelligence tools are
developed before integration into stable infrastructure layers.

---

# 📡 Platform Structure

Satoshium is organized as a layered coordination system:

satoshium.ai architecture layer
satoshium.net infrastructure layer
satoshium.info knowledge layer
satoshium.xyz experimental layer

The experimental layer allows structured exploration without affecting
platform stability.
